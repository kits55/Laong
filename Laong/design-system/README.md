Laong (ละออง) คือชุดหน้าตาสำหรับแอป SprayDry Copilot: เว็บควบคุมและบันทึกการทดลองเครื่อง Spray Dryer ที่ผู้ใช้หน้างานเปิดใช้ได้ทั้งมือถือ iPad Laptop และจอ desktop. ชุดนี้เปลี่ยนเฉพาะหน้าตาและการจัดวาง ฟังก์ชัน สูตร และ core ของแอปเดิมอยู่ครบและแก้ไม่ได้ผ่านชุดนี้.

ข้อมูลในระบบนี้เป็นข้อมูลภายในทีม ห้ามนำออกนอกทีม ห้ามใส่ค่าคาลิเบรตจริงหรือผลทดลองจริงในตัวอย่าง. ตัวเลขทุกตัวที่เห็นในหน้าตัวอย่างเป็นข้อมูลสมมติ.

## กฎที่ต้องทำตามทุกหน้า

- ห้ามเปลี่ยนสูตร ฟังก์ชัน หรือ id ของช่องกรอกในแอปเดิม. ชุดนี้ให้เฉพาะคลาส CSS, โครงหน้า และข้อความช่วยเหลือ (รายละเอียดใน "กติกา core").
- ค่าที่ไม่มีต้องเว้นว่างและแสดงว่า "ยังไม่มีค่า" เสมอ. ห้ามแสดงเป็น 0, NaN หรือ null.
- ทุกตัวเลขมีป้ายที่มาจาก StatusChip. Measured, Observed, Calculated, Predicted, Proxy, Assumed, Validated ห้ามปนในค่าเดียวกัน.
- ผลคำนวณที่ยังไม่ผ่านตรวจสอบติดป้าย `unvalidated` และคำว่า "คำนวณ UNVALIDATED" เสมอ.
- ป้าย Synthetic, TEST และ UNVALIDATED ของแอปเดิมต้องอยู่ทุกหน้า.
- ช่องกรอกตัวหนังสือ 16px ขึ้นไป ปุ่มและช่องสูง 44px ขึ้นไป.

## น้ำเสียงและคำ

เขียนจากมุมของคนหน้าเครื่อง เรียกสิ่งที่เขารู้จัก ไม่เรียกตามชื่อโมดูลในโค้ด. ปุ่มเป็นคำกริยาที่บอกผลตรง ๆ: "บันทึกรัน", "ประเมิน Tout", "ส่งออก CSV". ข้อความ error บอกว่าผิดอะไร ทำไม และแก้อย่างไร.

ศัพท์เทคนิคคงเป็นอังกฤษตามที่แอปเดิมใช้: Tout, Tin, Tg, Brix, Proxy, DOE, Run Review, Calibration. คำอธิบายรอบข้างเป็นภาษาไทยสั้น ๆ. ไม่ใช้อีโมจิ ไม่ใช้เครื่องหมายตกใจ. ตัวอย่างข้อความจริง: "ขาดค่า Tin กรอก Tin ก่อน ระบบจึงจะคำนวณ Tout ให้".

## การมองเห็น

สี: พื้นหน้า `surface-100` (ขาวอมเทาอบอุ่นเหมือนผง) พื้นกล่อง `surface-200` ข้อความ `ink` และ `ink-muted`. สีหลักเป็นเขียวน้ำทะเลเข้ม `brand` ใช้กับปุ่มหลัก ลิงก์ และขั้นปัจจุบัน ใช้อย่างประหยัด. สีสถานะ (`danger`, `warn-*`, `ok-*`) และสีที่มาของข้อมูล (`st-*`) ใช้เฉพาะความหมายของมัน ห้ามนำไปตกแต่ง. ทุกคู่ข้อความกับพื้นผ่าน 4.5:1 ทั้งโหมดสว่างและมืด (ตรวจแล้ว), ขอบของช่องกรอกผ่าน 3:1.

ตัวอักษร: `IBM Plex Sans Thai` สำหรับข้อความ ซึ่งรองรับไทยและละตินในชุดเดียว และ `IBM Plex Mono` สำหรับตัวเลข ใช้แบบ tabular ให้หลักตรงกัน. ฟอนต์ทั้งสองโหลดจาก Google Fonts (ไม่มีไฟล์ฟอนต์ในชุดนี้). ขนาดเล็กสุด 13px ใช้กับ hint เท่านั้น. ความสูงบรรทัดข้อความไทยไม่ต่ำกว่า 1.5.

ระยะ: สเกล 4, 8, 12, 16, 24, 32, 48 px. ขอบข้างของหน้า 16px บนมือถือ. มุมโค้ง 4px (chip), 8px (ปุ่ม ช่อง), 12px (Panel). ใช้เส้น `line` แบ่งกล่อง ใช้เงา `shadow-1` เฉพาะ Panel. ไม่มีไล่สี ไม่มีเงาหนา.

การเคลื่อนไหว: มีเพียงเปลี่ยนสีพื้นปุ่ม 120ms และปิดเมื่อผู้ใช้ตั้ง reduced motion.

โฟกัสแป้นพิมพ์: วงทึบ 3px สี `focus` ห่าง 2px ทุกชิ้นที่กดได้.

## ไอคอน

ใช้อักขระข้อความเท่านั้น (●, ◐, ƒ, ◇, ≈, ?, ✓, !, ▲, ✕, i) ใน chip และ Notice เพื่อไม่ต้องมีไฟล์ภาพ และตัวอักษรเหล่านี้ใส่ `aria-hidden="true"` เพราะมีคำกำกับอยู่แล้ว. ถ้าต้องการไอคอนภาพในอนาคต ให้ใช้ชุดเส้นเดียวกันทั้งแอปและบันทึกที่นี่ก่อน.

## วิธีใช้

1. โหลด `tokens.css`, `components/bundle.css` และ Google Fonts ตามลำดับ.
2. ใส่ `ld-root` ที่ `body` และสลับโหมดมืดด้วย `data-theme="dark"` ที่ `html`.
3. สร้างหน้าจากโครง AppShell แล้วใส่ Panel, Field, Metric, DataTable ตามหน้าที่ในแผนที่ฟังก์ชัน.
4. ก่อนส่งงาน ทดสอบที่ 390, 768, 1280 และ 1440 px ตามหน้า "กติกาโครงหน้า".

## ที่ยังไม่ครอบคลุม

Snap-to-Read (ถ่ายรูปอ่านค่า), ระบบ Machine ID, แดชบอร์ดผู้บริหาร และกราฟ ยังไม่มีคอมโพเนนต์. ทั้งสามอย่างต้องให้เจ้าของโปรเจกต์ตัดสินเรื่องป้ายที่มาของข้อมูลก่อน (ค่าที่อ่านจากรูปจะเป็น Observed หรือชนิดใหม่) จึงเว้นไว้ไม่เดา.
