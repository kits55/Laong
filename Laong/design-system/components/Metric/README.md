การ์ดค่าตัวเลขหนึ่งค่า: `ld-metric` ประกอบด้วย `ld-metric__label`, `ld-metric__value` + `ld-metric__unit` และแถว `ld-metric__meta` ที่ใส่ StatusChip.

ผู้ใช้ต้องจัดหา: ค่า หน่วย และที่มา. ค่าตัวเลขใช้ฟอนต์ mono แบบ tabular เพื่อให้หลักตรงกันเมื่อเทียบหลายการ์ด.

- ทุก Metric ต้องมีป้ายที่มาอย่างน้อย 1 ป้าย.
- ถ้ายังไม่มีค่า ให้ใช้ `ld-metric__empty` เขียนว่า "ยังไม่มีค่า" และห้ามแสดง 0, NaN หรือ null.
- ค่าที่ยาวมากจะตัดบรรทัดได้ (`overflow-wrap: anywhere`) ห้ามตัดด้วย ellipsis เพราะตัวเลขต้องอ่านครบ.
- ในโครงเดียวกัน ใช้ `ld-grid` วางหลายการ์ด จะเรียงตามความกว้างจอเอง.
