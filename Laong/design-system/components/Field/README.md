ช่องกรอก: `ld-field` ห่อ `ld-label`, `ld-input-wrap` (ใส่ `ld-input`, `ld-select` หรือ `ld-textarea`), `ld-unit` และ `ld-hint` หรือ `ld-error`.

ผู้ใช้ต้องจัดหา: `id` เดิมของช่องในแอปต้นฉบับ (ห้ามเปลี่ยน id เพราะสคริปต์เดิมอ้างถึง), หน่วย, และข้อความ hint.

- ตัวหนังสือในช่องกรอกต้อง 16px ขึ้นไปเสมอ ไม่เช่นนั้น iOS จะซูมหน้าจอเอง.
- ช่องตัวเลขใช้ `ld-input--num` และ `inputmode="decimal"`. หน่วยอยู่ใน `ld-unit` ด้านขวา ไม่ใส่หน่วยในตัวเลข.
- ค่าที่ไม่มีต้องเว้นว่างและแสดง placeholder "ยังไม่มีค่า". ห้ามเติม 0 แทน.
- Error บอก 3 อย่าง: ผิดอะไร ทำไม แก้อย่างไร. ตั้ง `data-invalid="true"` ที่ `ld-field` และผูก `aria-describedby`.
- ป้ายชื่อต้องอยู่เหนือช่องเสมอ ห้ามใช้ placeholder เป็น label.
