ตารางรายการ เช่น ประวัติรัน: `ld-table-wrap` > `table.ld-table`. ตัวเลขใส่ `ld-num` เพื่อชิดขวาและตรงหลัก.

แบบการ์ดบนมือถือ: ใช้ `ld-table-wrap ld-table-wrap--cards` และ `ld-table ld-table--cards` แล้วใส่ `data-label` ในทุก `td`. ใช้เมื่อ `ld-shell` แคบกว่า 700px จึงเปลี่ยนเป็นการ์ดเอง. ต้องมี `.ld-shell` ครอบตาราง.

ผู้ใช้ต้องจัดหา: ข้อมูลแถว และ `data-label` ที่ตรงกับหัวคอลัมน์.

- ช่องที่ไม่มีค่าเขียนว่า "ยังไม่มีค่า" ห้ามเว้นว่างเปล่าและห้ามใส่ 0.
- คอลัมน์ที่มาของข้อมูลใช้ StatusChip.
- ตารางที่กว้างเกินจอเลื่อนข้างในกรอบ `ld-table-wrap` ห้ามให้ทั้งหน้าเลื่อนข้าง.
- ห้ามย่อหัวคอลัมน์เป็นตัวย่อที่ผู้ใช้หน้างานไม่รู้จัก.
