ปุ่มสำหรับสั่งงาน ใช้คลาส `ld-btn` ตามด้วยแบบที่ต้องการ: `ld-btn--primary`, ไม่ใส่อะไรเลยสำหรับปุ่มรอง, `ld-btn--quiet`, `ld-btn--danger`, `ld-btn--block`.

ผู้ใช้ต้องจัดหา: ข้อความปุ่มที่เป็นคำกริยา (เช่น "บันทึกรัน" ไม่ใช่ "ตกลง") และ handler ของงานเดิม. ห้ามสร้างตรรกะใหม่ในปุ่ม ให้เรียกฟังก์ชันเดิมของแอป.

- ปุ่มหลัก (`primary`) ใช้ 1 ปุ่มต่อ Panel เท่านั้น.
- ปุ่ม `danger` ใช้กับงานที่ย้อนไม่ได้ และต้องมีขั้นยืนยันบนหน้าจอ.
- ความสูงขั้นต่ำ 44px (`touch`) เพื่อให้นิ้วกดได้ในโรงงาน. อย่าลดความสูง.
- ปุ่มที่ปิดอยู่ใช้ `disabled` และเขียนเหตุผลที่ปิดไว้ข้างปุ่ม.
- วงโฟกัสเป็นสี `focus` ห่างจากปุ่ม 2px อย่าลบทิ้ง.
