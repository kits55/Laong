แถบข้อความในหน้า: `ld-notice` + `data-kind` เป็น `info`, `warn`, `danger`, `ok` หรือ `unvalidated`. ใส่ `role="alert"` กับ error ที่ต้องรู้ทันที และ `role="status"` กับข้อความทั่วไป.

ผู้ใช้ต้องจัดหา: หัวข้อสั้น 1 บรรทัด และเนื้อหาบอกว่าเกิดอะไร ทำไม ต้องทำอย่างไรต่อ.

- ป้าย Synthetic, TEST และ UNVALIDATED ของแอปต้นฉบับต้องคงอยู่ทุกหน้า ใช้ `data-kind="info"` สำหรับ Synthetic/TEST และ `data-kind="unvalidated"` สำหรับผลที่ยังไม่ผ่านตรวจสอบ.
- ข้อความเตือนทางวิทยาศาสตร์ห้ามตัดหรือซ่อนใน details. จะย่อให้สั้นลงได้ แต่ต้องคงความหมาย.
- มีไอคอนและหัวข้อเสมอ ไม่ใช้สีพื้นอย่างเดียว.
