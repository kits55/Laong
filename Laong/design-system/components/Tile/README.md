การ์ด "ที่วางไว้ในดีไซน์ ยังไม่เปิดใช้" (`.tile`, `.soon`) ใช้วางตำแหน่งของที่ยังไม่มีสเปก: Snap-to-Read, Machine ID, แดชบอร์ดผู้บริหาร, ฐานข้อมูลงานวิจัย, พยากรณ์คุณภาพผง, บัญชีผู้ใช้จริง.

ผู้ใช้ต้องจัดหา: ชื่อ คำอธิบายสั้นว่าจะทำอะไร และสิ่งที่ยังรอ (เช่น รอรูปหน้าจอจริงและรุ่นเครื่อง).

- ขอบประ และป้าย "ยังไม่เปิดใช้" ทุกใบ ไม่ใช้สีสถานะ
- ห้ามใส่ตัวเลข กราฟตัวอย่าง หรือค่าสมมติเพื่อให้การ์ดดูเต็ม
- บอกชัดว่ารออะไร เพื่อให้เจ้าของระบบรู้ว่าต้องส่งข้อมูลอะไร
- Snap-to-Read: ค่าที่อ่านจากรูปยังไม่มีป้ายที่มาที่ตัดสินแล้ว (Observed หรือชนิดใหม่) รอเจ้าของระบบ
- Machine ID: ตอนนี้ใช้รหัสตัวอย่างเช่น SYN-A ในกล่อง `.machine__code` เท่านั้น
- แดชบอร์ดผู้บริหาร: ถ้าจะมีกราฟ ใช้ Chart และกฎ dataviz เดียวกัน

ตัวอย่างในหน้าภาพรวมของแอป (`src/pages/Overview.tsx`) และ `preview.html`.
