กราฟจุดและเส้นแบบหนึ่งแกน (`PointsChart` ใน `src/ui/charts.tsx`) สร้างจาก SVG ไม่ใช้ไลบรารี ใช้ตามหลัก dataviz ของ Laong.

ผู้ใช้ต้องจัดหา: ข้อมูลของแต่ละชุด (`series`), ที่มาของข้อมูล (`kind` ใช้ 9 ชนิดเดียวกับ StatusChip), และตารางคู่กราฟ (`table`).

- หนึ่งแกน หน่วยเดียว ห้ามวางสองหน่วยในกราฟเดียว (เช่น °C กับ %)
- ไม่ใช้สีอย่างเดียว: ชุดข้อมูลต่างกันที่รูปจุด (`circle` ทึบ, `square` กลวง) และลายเส้น (ทึบ, ประ) สีของชุดมาจากสีของป้ายที่มา (`--st-*-fg`) จึงตรงกับ StatusChip
- ค่า `null` ไม่ถูกวาดเป็น 0 เส้นขาดช่วงและไม่มีจุด ถ้าทั้งกราฟไม่มีข้อมูลจะขึ้นข้อความ `emptyText`
- ต้องมีตารางคู่กราฟเสมอ (`<details>` ใต้กราฟ) และมีคำอธิบายของกราฟใน `aria-label`
- แถบ `band` ใช้ทำแนวอ่านผล เช่น ราว 5 °C รอบค่าที่ทำนาย ใช้พื้น `brand-soft` และมีป้ายข้อความกำกับ
- เส้นวาดเข้าครั้งเดียว 700ms แล้วหยุด ปิดเมื่อ reduced motion
- ความกว้างวัดจากกล่องจริง (ResizeObserver) ตัวอักษรบนแกนจึงไม่เล็กลงบนมือถือ
