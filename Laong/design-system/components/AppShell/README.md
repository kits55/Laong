โครงหน้าของแอป: `.ld-shell` > `.ld-shell__frame` > (`nav.ld-steps` + `main.ld-shell__main`). ใส่ `ld-root` ที่ `body` หรือกล่องนอกสุด.

โหลดไฟล์ตามลำดับ: `tokens.css`, `components/bundle.css`, แล้ว Google Fonts: `https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Thai:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap`.

ผู้ใช้ต้องจัดหา: เนื้อหาใน `main` และลิงก์ของแถบขั้นตอน. โครงนี้ไม่ผูกกับสคริปต์ใด ๆ ของแอปเดิม จึงเปลี่ยนเฉพาะหน้าตาได้.

| ความกว้างของ shell | แถบนำทาง | ขอบเนื้อหา |
|---|---|---|
| ต่ำกว่า 700px (มือถือ 390px) | แถบล่างติดจอ | 16px |
| 700 ถึง 999px (iPad 768px) | แถบบนติดจอ | 24px |
| 1000px ขึ้นไป (Laptop 1280px, จอใหญ่ 1440px) | แถบซ้าย 248px | 32px ถึง 48px, กว้างไม่เกิน 1180px |

- เลย์เอาต์ดูความกว้างของ `ld-shell` เอง (container query) จึงฝังในกรอบเล็กได้.
- ห้ามให้ทั้งหน้าเลื่อนข้าง. ตารางหรือกราฟที่กว้างให้เลื่อนในกรอบของตัวเอง.
- เนื้อหาเรียงเป็นคอลัมน์เดียวบนมือถือ และใช้ `ld-grid` ให้ขยายเป็นหลายคอลัมน์เองบนจอกว้าง.
