# Laong

เปิด `index.html` ด้วย Edge หรือ Chrome เพื่อใช้แอปบนเครื่อง หรือเสิร์ฟโฟลเดอร์นี้ด้วย Static Server เดิมที่มีอยู่ ถ้าเบราว์เซอร์บล็อกการจัดเก็บจากไฟล์โดยตรง

## ลองทำหนึ่งรัน

1. กดสร้างการทดลอง แล้วเลือก Spray Dryer หรือการทดลอง R&D
2. กรอกแผน ยืนยัน แล้วกดเริ่มทดลอง
3. เพิ่มค่าหรือเหตุการณ์ระหว่างทดลองได้หลายครั้ง กดจบการทดลองเมื่อพร้อมกรอกผล
4. ใส่ผลหลังทดลองแล้วปิดรัน เปิดย้อนหลังได้ในเมนูประวัติ
5. ดาวน์โหลด Word และ Excel หรือกด PDF แล้วเลือก Save as PDF ในหน้าพิมพ์

ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ที่เปิดแอป การย้ายเครื่อง เปลี่ยนโปรไฟล์เบราว์เซอร์ หรือล้าง Site Data จะเปลี่ยนพื้นที่ที่ใช้เก็บข้อมูล รุ่นนี้เหมาะกับข้อมูลตัวอย่าง และมีจุดรอไฟล์โมเดล Tout ที่ยืนยันแล้วก่อนเปิดการคำนวณ

## เพิ่มจาก Desktop Pack

- เปิดเมนูเครื่องเพื่อเพิ่ม Machine ID ชื่อ 2–40 ตัวอักษร การจองเลขใช้ Web Locks ของเบราว์เซอร์และใช้ได้ภายในพื้นที่จัดเก็บเดียวกัน
- ETA L1 ใช้ปริมาตรสะสมและอัตราป้อนจริงล่าสุดที่บันทึก ส่วน L2 แสดงช่วงเวลาป้อนทั้งหมดของรันที่ปิดแล้วบนเครื่องเดียวกันเมื่อมีเวลาเริ่มและจบป้อนอย่างน้อย 3 รัน
- หน้าแจ้งเตือนมีรายการป้อนครบและรอผลแล็บ ตั้งค่าเปิดปิดได้ รวมถึงกำหนดเครื่องเริ่มต้น รันที่ปิดแล้วทำสำเนาเฉพาะแผนเป็นร่างใหม่ได้
- หน้า Admin และผู้บริหารเปิดจากเมนูตั้งค่า ใช้ข้อมูลสังเคราะห์ของพรีวิว สิทธิ์จริง การอนุมัติบัญชี การจัดการเครื่องโดย Admin และ Audit Log ฝั่ง Server รอระบบบัญชีและ Backend

## ทะเบียนเครื่องและปฏิทิน

- ค้นเครื่องด้วยชื่อหรือ Machine ID และกรองสถานะ เมื่อตามไปสร้างหรือเปิดรันจากทะเบียน ปุ่มย้อนกลับจะคืนตัวกรองในแท็บเดิม
- เปิดปฏิทินแล็บ เลือกวัน แล้วเพิ่มแผนพร้อมเวลาเริ่มและเวลาสิ้นสุด (ถ้ามี) แก้ไขหรือลบได้ วันที่และเวลายึดเวลาไทย แผนเก็บบนเบราว์เซอร์นี้และไม่ใช่การจองเครื่อง
- การเขียนรันใช้ Web Locks และตรวจข้อมูลล่าสุดเพื่อป้องกันสองแท็บเขียนทับกัน หลังอัปเดตให้รีเฟรชทุกแท็บที่เปิด Laong ค้างไว้

## ไฟล์

- `app.js` จัดการ Template, Lifecycle, UI และข้อมูลในเครื่อง
- `workspace.js` จัดการเครื่อง การตั้งค่า แจ้งเตือน และ ETA
- `previews.js` แสดงบอร์ด Admin และผู้บริหารจากข้อมูลสังเคราะห์
- `reports.js` สร้าง Word, Excel และหน้าพิมพ์ PDF จากรันเดียวกัน
- `tokens.css` และ `icons/` มาจาก Laong Desktop Pack
- `docs/BLUEPRINT.md` ระบุ Requirements และขอบเขตก่อนนำไปใช้งานร่วมกัน
