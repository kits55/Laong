- [ ] ค่าที่ไม่มีแสดงว่า "ยังไม่มีค่า" ไม่ใช่ 0 [BRIEF]
- [ ] ผลทำนาย Tout ติดป้าย UNVALIDATED เสมอ [BRIEF]
- [ ] ตัวเลขเดียวกันต้องตรงกันทุกหน้า (จำนวนรันที่กำลังรัน, จำนวนเครื่อง, จำนวนรันที่ปิดแล้ว) ตอนทดสอบเว็บเวอร์ชัน Next.js เจอ "2 / 4 กำลังรัน" แต่หน้าอื่นบอกว่ามี 1 รัน [QA]

## 2. ปุ่มและการโต้ตอบ

- [ ] ปุ่มสลับสองสถานะ (เช่น ธีม) กดครั้งเดียวต้องเปลี่ยนสิ่งที่เห็นทันที และไอคอนตรงกับสิ่งที่เห็นอยู่ ไม่ใช่ค่าที่เก็บไว้ (บั๊กเดิม: ค่าเริ่มต้น "ตามเครื่อง" ทำให้ต้องกดสามรอบ) [QA]
- [ ] ปุ่มไอคอนทุกปุ่มมีชื่อให้โปรแกรมอ่านหน้าจอ (`aria-label`) ปุ่มเปิดปิดกลุ่มเมนูของเวอร์ชัน Next.js ไม่มีชื่อ [QA]
- [ ] ปุ่มที่ยังกดไม่ได้ถูกล็อก และบอกเหตุผลได้ [QA]
- [ ] ปุ่มที่เปิดลิ้นชักหรือหน้าต่างปิดได้ด้วยปุ่มปิดและแป้นพิมพ์ [QA]
- [ ] ไล่กดทุกปุ่มแล้วไม่มี error ในคอนโซล ข้ามปุ่มลบ ล้าง ส่งออก พิมพ์ และติดตั้งเมื่อไล่แบบอัตโนมัติ (ปุ่มพิมพ์ทำให้หน้าค้างตอนรันสคริปต์) [QA]
- [ ] ปุ่มหลักหนึ่งปุ่มต่อหนึ่งหน้าจอ ปุ่มรองหนึ่งปุ่ม [IG: unslop]

- [ ] ไม่มี NaN, Infinity หรือ undefined แสดงบนหน้าจอ [QA]

- [ ] ธีมสว่างและมืดอ่านออกทั้งคู่ ข้อความเทาบนพื้นเทาเข้มต้องวัดคอนทราสต์ (ตัวเนื้อหา 4.5 ต่อ 1 ขึ้นไป) [BRIEF]
- [ ] ผู้ใช้ตั้ง reduced motion แล้วอนิเมชันลดลง แต่ป้ายสถานะยังชัด [BRIEF]
- [ ] ใช้งานครบด้วยแป้นพิมพ์ มีวงโฟกัสที่เห็นชัด [BRIEF]

## 7. การเคลื่อนไหวและมาสคอต

- [ ] มาสคอตไม่บังปุ่มหรือเนื้อหา ลากได้ ซ่อนได้ และจำค่าที่ผู้ใช้ตั้ง
- [ ] ท่ามาสคอตใหม่ผ่านการอนุมัติจากเจ้าของแบรนด์ก่อนใช้จริง [BRIEF]

## 8. วิธีตรวจด้วยภาพจริง [IG: taste-skill]

1. รันแอป แล้วถ่ายภาพหน้าจอที่ 3 ขนาด ทั้งธีมสว่างและมืด
2. อ่านค่าจาก DOM (ขนาดเล็กสุด, ล้นจอ, ชื่อปุ่ม) แทนการเดาจากภาพ
3. แก้จากสิ่งที่เห็น แล้วถ่ายใหม่ไม่เกิน 3 รอบ
4. บันทึกผลที่ยังไม่ผ่านไว้ในรายงาน แยกเป็น Confirmed, Suspected, Missing test, Expected
