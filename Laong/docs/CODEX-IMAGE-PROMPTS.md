# ชุด Prompt ให้ Codex สร้างภาพ LaOng (ครบทุกท่าและทุกภาพ)

เอกสารนี้ไม่มีข้อมูลจริงของทีม ทุกภาพเป็นภาพประกอบทั่วไป ไม่มีตัวเลขหรือค่าคาลิเบรต

Keep the same proportions and face placement in every pose. Only the face, tilt, props and small details change.

## 3. Prompt สำเร็จรูปรายท่า (ต่อท้ายข้อกำหนดกลางในข้อ 0)

ใช้รูปแบบนี้กับทุกท่า แล้วเปลี่ยนส่วน POSE

```
[วางข้อกำหนดกลางข้อ 0]

POSE: <ชื่อท่า>
Output file: <ชื่อไฟล์>.svg
Details: <ข้อความจากตารางด้านบน>
Do not change the body shape, face placement, colors, or shadow position.
Return the SVG code only, then a one-line description.
```

ตัวอย่างท่า 19:
```
POSE: thinking
Output file: mascot-thinking.svg
Details: eyes glance up and to the right, small closed smile, three small teal dots floating beside the head forming a thinking bubble.
```

ทุกภาพต้องมีเวอร์ชัน `-dark` ที่ปรับสีพื้นหลัง เงา และหยดให้ตรงกับโทเค็นมืด ส่วนตัวน้องละอองคงสีตัวไว้ ปรับแค่เงาและหยดเป็น `#5DC3CA`

## 6. ข้อห้าม (คัดจาก BRIEF และชุดดีไซน์)

- ห้ามมีข้อความภาษาใดในภาพ
- ห้ามมีตัวเลขหรือค่าที่เหมือนผลทดลองจริง
- ห้ามมีโลโก้หรือชื่อขององค์กรภายนอก
- ห้ามมีเพศ ศาสนา หรือการเมืองในตัวละคร
- มาสคอตห้ามใช้ในหน้าที่มีเตือนหรือข้อผิดพลาด และห้ามใช้ใน Dashboard ผู้บริหาร (กฎจากชุดดีไซน์เดิม) ท่า 19–22 ใช้เฉพาะหน้าโหลดและปุ่ม
- ท่าอารมณ์เชิงลบ (31 เหนื่อย, 32 ตกใจ, 33 น้อยใจ) ใช้ได้เฉพาะเป็นปฏิกิริยาเล่น ๆ เมื่อผู้ใช้ลากหรือกดมาสคอต ห้ามใช้ในหน้าที่มีเตือนหรือข้อผิดพลาด

## 13. ผลตรวจชุดที่แก้แล้ว (รอบที่ 4 ส่งกลับ, 15 พ.ย. 2569)

เทียบไฟล์กับชุดก่อนหน้าด้วย hash และดูภาพที่เปลี่ยนทั้งสองธีม

| ข้อ | ผล | หลักฐาน |
|---|---|---|
| F1 ภาพ 6 ภาพใช้น้องละอองตัวมาตรฐาน | ผ่าน `[confirmed]` | 12 ไฟล์เปลี่ยน ดูภาพแล้วตัวสีมิ้นต์ ตา แก้มส้ม ตรงกับ `mascot-idle` ทั้งสองธีม |
| F2 favicon อ่านได้บนพื้นมืด | ผ่าน `[confirmed]` | เป็นสี่เหลี่ยมโค้งมนสีเขียวเข้มมีเครื่องหมายขาว |
| F3 ไอคอนจดค่าใน `story-flow` | ผ่าน `[confirmed]` | เป็นสมุดกับดินสอ อ่านออกในภาพรวม |
| F4 `look-left`, `look-right` | ผ่าน `[confirmed]` | ตาเหลือบไปด้านที่มองชัดกว่าเดิม |
| N1–N5 ภาพใหม่ 5 รายการ x 2 ธีม | ผ่าน `[confirmed]` | viewBox 320x200 ไม่มีข้อความ N1–N2 ไม่มีมาสคอต |

**ยังไม่ได้ตรวจ `[open]`:** การแสดงผลในแอปจริงที่ขนาดจริง (โดยเฉพาะ `pattern-droplets` ธีมสว่าง, `fog`, `favicon` ขนาด 16 px) และท่าใหม่ 33 ท่ายังรอผู้ดูแลแบรนด์ยืนยัน
สำเนาเก็บไว้ที่ `reference\codex-svg-assets-v2\` และ `reference\codex-web-extras-v2\` (v1 เป็นรุ่นก่อนแก้ ลบได้เมื่อยืนยัน)
