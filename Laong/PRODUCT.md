## Platform

web

## Stack

HTML, CSS และ JavaScript สำหรับเวอร์ชันทดลองบนเครื่อง เปิดจากเบราว์เซอร์ได้โดยไม่ต้องติดตั้ง Dependencies

## ผู้ใช้และงาน

ทีมวิจัยและพัฒนาผลิตภัณฑ์ใช้ Laong เพื่อบันทึกแผน เหตุการณ์ ค่าที่อ่านจริง และผลหลังทดลองลงในรันเดียว และส่งต่อข้อมูลเป็นรายงาน

## ขอบเขต

- Template เริ่มต้นมี Spray Dryer และการทดลอง R&D
- ข้อมูลบันทึกในเบราว์เซอร์ที่ใช้งาน รุ่นทดลองมีข้อมูลสังเคราะห์
- Tout Prediction เป็นส่วนของ Spray Dryer มีจุดรอไฟล์โมเดลและกรณีอ้างอิงจากเจ้าของโมเดล
- Export PDF ผ่านหน้าพิมพ์ของเบราว์เซอร์ ส่วน Word และ Excel ดาวน์โหลดจากหน้ารันที่ปิดแล้ว
