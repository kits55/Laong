# Prompt สำหรับให้ AI สร้างหน้าจอจากชุดนี้

ใช้แบบแบ่งเฟส ทีละหน้า ไม่สั่งทั้งแอปในครั้งเดียว. คัดลอกกรอบด้านล่างแล้วเปลี่ยนค่าในวงเล็บเหลี่ยม.

```
บทบาท: Senior Front-end developer ของแอป B2B ควบคุมเครื่อง Spray Dryer

บริบท:
- ใช้ design system "Laong": tokens.css, components/bundle.css, คลาส ld-*
- หน้าที่จะทำ: [ชื่อหน้า เช่น "2 ระหว่างทดลอง"]
- ฟังก์ชันเดิมที่ต้องอยู่ครบ: [ลิสต์จาก function-map]
- ไฟล์ที่แก้ได้: [CSS และไฟล์จัดวางที่ระบุ] ห้ามแตะไฟล์ core ในกติกา core

ข้อกำหนด:
1. ก่อนแก้ ให้ตรวจโครงสร้างโปรเจกต์ที่มีอยู่และเก็บรายการ id ของช่องกรอกทั้งหมด
2. คง id ลำดับสคริปต์ และ listener เดิม ห้ามสร้าง Timer/Store/Prediction ใหม่
3. ทุกตัวเลขมี StatusChip ที่มา ค่าที่ไม่มีแสดง "ยังไม่มีค่า" ห้ามแสดง 0
4. ใช้เฉพาะ token และคลาส ld-* ห้ามใส่สีหรือขนาดตัวอักษรเอง
5. ใช้ข้อมูลสมมติเท่านั้น ห้ามค่าคาลิเบรตจริง

ผลลัพธ์ที่ต้องส่ง:
- ไฟล์ที่เปลี่ยน พร้อมสรุปสั้น ๆ ว่าเปลี่ยนอะไร
- ภาพก่อน/หลังที่ 390, 768, 1280, 1440 px
- ผลตรวจ: id เดิมครบ, hash ไฟล์ core ไม่เปลี่ยน, ไม่มีหน้าเลื่อนข้าง, ช่องกรอก 16px ขึ้นไป
- รายการที่ยังไม่ได้ทดสอบหรือทำไม่ได้ เขียนตรง ๆ ว่า FAIL, BLOCKED หรือ NOT TESTED

ถ้าต้องเปลี่ยนสัญญาข้อมูลหรือแตะไฟล์ core ให้หยุดและถามก่อน
```

## ลำดับเฟสที่แนะนำ

1. โครงหน้า (AppShell, Steps) บนข้อมูลสมมติ ตรวจ 4 ขนาดจอ.
2. หน้า "1 ก่อนทดลอง" พร้อมช่องกรอกเดิมครบ.
3. หน้า "2 ระหว่างทดลอง" ที่ใช้บนมือถือหน้างาน.
4. หน้า "3 หลังทดลอง" และ "4 ประวัติ".
5. หน้า "5 รายงาน" และส่วนขั้นสูง.

แต่ละเฟสจบด้วยการทดสอบตามหน้า "กติกาโครงหน้า" ก่อนเริ่มเฟสถัดไป.
