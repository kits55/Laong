แถบ 5 ขั้นตอนหลักของการทำงาน: ก่อนทดลอง, ระหว่างทดลอง, หลังทดลอง, ประวัติ, รายงาน. ใช้ `<nav class="ld-steps">` ภายใน `ld-shell__frame` (ดู AppShell). แต่ละขั้นเป็น `<a class="ld-step" data-state="done|current|todo">`.

ผู้ใช้ต้องจัดหา: ลิงก์หรือ handler ที่เปลี่ยนหน้าของขั้นนั้น และใส่ `aria-current="step"` ที่ขั้นปัจจุบัน.

- ตำแหน่งปรับตามความกว้างของ `ld-shell`: ต่ำกว่า 700px แถบล่าง, 700 ถึง 999px แถบบน, 1000px ขึ้นไปแถบซ้ายพร้อมคำอธิบายใต้ชื่อ.
- ขั้นปัจจุบันไม่ใช้สีอย่างเดียว: พื้นอ่อน เส้นหนา และตัวเลขทึบ. ขั้นที่ทำแล้วขึ้น ✓.
- มีแถบนำทางเดียวในหน้า ห้ามซ้ำกับเมนูอื่นที่ชื่อเดียวกัน.
- ส่วนอื่นของแอป (ภาพรวม, ขั้นสูง, ตั้งค่า) ใช้ปุ่มรองในหัวหน้า ไม่แทรกในแถบ 5 ขั้นตอน.
